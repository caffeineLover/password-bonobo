# Security Policy

## Reporting a vulnerability

Do not include credentials, passwords, tokens, private keys, personal PasswordSafe databases, or other vault contents
in a public issue, pull request, discussion, or comment.  Public reports should contain only the minimum safe detail
needed to identify the affected Bonobo behavior.

Once it is enabled, report security concerns through the repository owner's private GitHub security reporting channel.
Until that channel is enabled, do not publish sensitive material in this repository.

## Scope

This project is in foundation development and does not yet provide a usable vault.  The reporting rule still applies to
documentation, test data, development tools, and future releases.
