\section{Dependency and Asset Provenance Ledger}\label{dependency-and-asset-provenance-ledger}

\subsection{Scope and review keys}\label{scope-and-review-keys}

This ledger records the repository\textquotesingle s current direct and transitive Python packages, isolated build
dependency, native runtime dependencies, GitHub Actions, documentation tools, and tracked repository assets. It records
observed facts without treating package metadata as a completed legal review. The project declares no runtime Python
dependencies, and none of the development or build packages below is bundled in the wheel.

Compact keys keep this source reviewable within the 120-character line limit:

\begin{itemize}
\tightlist
\item
  Relationship: \passthrough{\lstinline!DB!} direct build, \passthrough{\lstinline!DD!} direct development,
  \passthrough{\lstinline!DNR!} direct native runtime, \passthrough{\lstinline!DR!} direct runtime, and
  \passthrough{\lstinline!T!} transitive.
\item
  Constraint: \passthrough{\lstinline!N!} means not directly declared. Other values reproduce the declaration in
  \nolinkurl{pyproject.toml}.
\item
  Use: \passthrough{\lstinline!BT!} repository build/test/security tool, \passthrough{\lstinline!TS!} transitive tool
  support, \passthrough{\lstinline!CI!} hosted workflow, \passthrough{\lstinline!DG!} document generation or review,
  \passthrough{\lstinline!LT!} license text, \passthrough{\lstinline!FX!} structural test fixture, and
  \passthrough{\lstinline!TM!} typing marker.
\item
  Distribution: \passthrough{\lstinline!N!} not distributed with the package, \passthrough{\lstinline!S!} source
  repository or source distribution, and \passthrough{\lstinline!W!} wheel; \passthrough{\lstinline!A!} platform
  application artifact, and \passthrough{\lstinline!+!} joins every applicable distribution location.
\item
  Evidence: \passthrough{\lstinline!P!} \nolinkurl{pyproject.toml} or a machine-readable source pin,
  \passthrough{\lstinline!L!} \passthrough{\lstinline!uv.lock!}, \passthrough{\lstinline!M!} installed Core Metadata,
  \passthrough{\lstinline!V!} local version output, \passthrough{\lstinline!R!} tracked REUSE metadata or source, and
  \passthrough{\lstinline!W!} tracked workflow plus official Git-ref evidence.
\item
  Review: \passthrough{\lstinline!V!} verified repository-owned fact, \passthrough{\lstinline!MP!} metadata expression
  recorded with compatibility review pending, and \passthrough{\lstinline!P!} license or terms review pending.
  \nolinkurl{NOASSERTION} means the available evidence does not establish the fact.
\end{itemize}
