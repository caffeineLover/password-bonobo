\subsection{External checkout boundary}\label{external-checkout-boundary}

The default external research checkout is \passthrough{\lstinline!../Password Bonobo Research/gorilla!}, resolved from
the primary Password Bonobo repository root. An operator may use another location only if it is outside the Bonobo
repository; the pinned commit and verification procedure remain the same. The checkout is detached at the pinned commit
and is read-only for research use. It must not be modified, annotated, staged, copied into Bonobo, or included in a
product build.

Create the default checkout only after confirming that the target is outside the repository and does not already exist:

\begin{lstlisting}
$bonoboRoot = (Resolve-Path -LiteralPath '.').Path
$researchRoot = Join-Path (Split-Path -Parent $bonoboRoot) 'Password Bonobo Research'
$gorillaRoot = Join-Path $researchRoot 'gorilla'
New-Item -ItemType Directory -Force -Path $researchRoot
git clone --filter=blob:none --no-checkout https://github.com/zdia/gorilla.git $gorillaRoot
git -C $gorillaRoot checkout --detach 6728e85c05ac25357b8f19f541487b9d26a97402
\end{lstlisting}

For an existing target, first confirm that its \passthrough{\lstinline!origin!} is the approved repository and that its
worktree is clean. Do not reset, delete, or overwrite an existing checkout automatically.

\subsection{Identity and clean-worktree verification}\label{identity-and-clean-worktree-verification}

Run these commands against the external checkout before research and before recording evidence:

\begin{lstlisting}
git -C $gorillaRoot remote get-url origin
git -C $gorillaRoot rev-parse HEAD
git -C $gorillaRoot status --short
git -C $gorillaRoot show -s --format='%H%n%T%n%aI%n%s' HEAD
git -C $gorillaRoot symbolic-ref --short refs/remotes/origin/HEAD
\end{lstlisting}

The origin must be \nolinkurl{https://github.com/zdia/gorilla.git}, \passthrough{\lstinline!HEAD!} must be the pinned
commit, and \passthrough{\lstinline!status --short!} must produce no output. The \passthrough{\lstinline!show!} command
records the commit, tree, author date, and subject; the symbolic reference records the remote default-branch
observation.

\subsection{Evidence convention and permitted research
categories}\label{evidence-convention-and-permitted-research-categories}

Each later compatibility evidence record must use neutral prose and identify:

\begin{itemize}
\tightlist
\item
  Revision: the pinned upstream revision.
\item
  Location: repository-relative path and a line range or test name.
\item
  Evidence kind: source inspection, test observation, documentation, or change history.
\item
  Neutral observation: an observable behavior or an unresolved question without copied implementation text.
\end{itemize}

The approved research pass may inspect application workflows and user-visible behavior in
\nolinkurl{sources/gorilla.tcl}; data concepts and compatibility behavior in \nolinkurl{sources/pwsafe/*.tcl};
user-facing contracts in \nolinkurl{sources/help.txt}, message catalogs, and upstream README material; behavioral
examples and edge cases in \nolinkurl{unit-tests/**/*.test} and \nolinkurl{unit-tests/**/*.tcl}; and
compatibility-relevant upstream change history.

Gorilla material is evidence of behavior, not implementation material. Do not copy or adapt upstream source, comments,
identifiers, file organization, control flow, UI assets, translations, screenshots, test fixtures, or vault files. In
particular, upstream \passthrough{\lstinline!.psafe3!} files remain external research-only and may not enter Bonobo
tracked fixture paths. Do not quote source fragments in Bonobo product code or compatibility documents.

\subsection{Updating this baseline}\label{updating-this-baseline}

Changing the external revision requires separate review, a newly pinned immutable revision, an updated provenance entry,
and a neutral dossier delta. Preserve prior observations rather than replacing them solely because a later revision
differs, and keep every research checkout external and read-only throughout the update.
