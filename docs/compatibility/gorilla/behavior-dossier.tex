\section{Password Gorilla Neutral Behavior Dossier}\label{password-gorilla-neutral-behavior-dossier}

\subsection{Evidence convention}\label{evidence-convention}

Each statement uses a sequential three-digit \passthrough{\lstinline!GOR-BEH!} identifier. Evidence is recorded as
revision, relative path, line range or test name, evidence kind (\passthrough{\lstinline!source!},
\passthrough{\lstinline!test!}, \passthrough{\lstinline!help!}, \passthrough{\lstinline!message!}, or
\passthrough{\lstinline!observed!}), and a neutral behavioral observation. Source text, source identifiers, control
flow, and UI expression are not reproduced.

\subsection{Confidence}\label{confidence}

\begin{itemize}
\tightlist
\item
  \passthrough{\lstinline!Confirmed!}: supported by at least two independent evidence kinds or one executable black-box
  observation.
\item
  \passthrough{\lstinline!Supported!}: supported by one direct source, test, or user-documentation item.
\item
  \passthrough{\lstinline!Unverified!}: evidence is incomplete, contradictory, or unavailable in the research
  environment.
\end{itemize}
