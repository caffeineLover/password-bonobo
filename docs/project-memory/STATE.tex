\section{Password Bonobo Current State}\label{password-bonobo-current-state}

Last updated: 2026-08-22

\subsection{Overview and current state}\label{overview-and-current-state}

The repository is on branch \nolinkurl{foundation/compatibility-dossier}. The repository foundation and compatibility
dossier are complete and locally verified. Product behavior remains unimplemented: the typed package exposes identity
only and cannot open, edit, save, or audit a vault.

\subsection{Completed foundation artifacts}\label{completed-foundation-artifacts}

\begin{itemize}
\tightlist
\item
  Git, packaging, Python 3.14, source-structure, tracked-file, security, dependency, and REUSE policy foundations.
\item
  GPL-3.0-or-later licensing, security reporting, clean-room provenance, contribution hold, and iOS-exception planning.
\item
  A detached external Gorilla baseline record pinned at \nolinkurl{6728e85c05ac25357b8f19f541487b9d26a97402}.
\item
  A neutral dossier with 66 behaviors, a 45-row feature matrix, and 55 synthetic black-box test oracles.
  Gorilla\textquotesingle s post-save loss behavior is an Excluded characterization; Bonobo\textquotesingle s
  transactional no-loss oracle remains authoritative.
\item
  Typed compatibility-contract and clean-room expression checks, including exact feature/evidence/oracle closure.
\item
  A checked dependency and asset provenance ledger, exact document generator/verifier, and GPL wheel assertion.
\item
  A three-platform CI definition and reproducible Markdown, LaTeX, ignored review-PDF, and page-render workflow.
\item
  A canonical \nolinkurl{docs/PROJECT_MEMORY.md} future-agent entry point routing to the four focused durable records.
\end{itemize}

\subsection{Active risks}\label{active-risks}

\begin{itemize}
\tightlist
\item
  The App Store distribution exception, contributor permissions, dependency eligibility, and current Apple terms remain
  unresolved and block external contributions and an iOS distribution build.
\item
  Some Gorilla behaviors remain explicitly Unverified; they do not establish parity until black-box evidence is reviewed
  and the dossier and matrix are updated.
\item
  Python 3.14 support for future binary and mobile dependencies must be requalified in the owning subproject.
\item
  The introduced GitHub Actions workflow has not yet run on the hosted service; only its complete local equivalent has
  passed.
\item
  Generated review PDFs are intentionally ignored and must be regenerated from committed Markdown and LaTeX sources.
\end{itemize}

\subsection{Next approved subproject}\label{next-approved-subproject}

The next approved subproject is \textbf{Lossless PasswordSafe core}. It owns typed PasswordSafe parsing, writing,
validation, unknown-field preservation, transactional local files, and conformance, fuzz, and round-trip suites.
