\section{Password Bonobo Current State}\label{password-bonobo-current-state}

Last updated: 2026-08-31

\subsection{Overview and current state}\label{overview-and-current-state}

Branch \nolinkurl{feature/lossless-passwordsafe-core} has a complete, locally verified repository foundation and
compatibility dossier plus the first ten implementation checkpoints of the approved lossless PasswordSafe core plan.
Internal typed modules can authenticate, parse, mutate, serialize, and transactionally replace supported PasswordSafe V3
vaults, but the package still exposes no service facade and retains version \passthrough{\lstinline!0.0.0!}.

\subsection{Completed foundation artifacts}\label{completed-foundation-artifacts}

\begin{itemize}
\tightlist
\item
  Git, Python 3.14 packaging, source-structure, tracked-file, security, dependency, REUSE, GPL-3.0-or-later, reporting,
  clean-room provenance, contribution-hold, and iOS-exception foundations.
\item
  A detached external Gorilla baseline record pinned at \nolinkurl{6728e85c05ac25357b8f19f541487b9d26a97402}.
\item
  A neutral dossier with 66 behaviors, a 45-row feature matrix, and 55 synthetic black-box test oracles.
  Gorilla\textquotesingle s post-save loss behavior is an Excluded characterization; Bonobo\textquotesingle s
  transactional no-loss oracle remains authoritative.
\item
  Typed clean-room and exact compatibility-closure checks, a checked dependency/asset provenance ledger, an exact
  document generator/verifier, and wheel/source-distribution asset assertions.
\item
  Three-platform CI and reproducible Markdown, LaTeX, ignored review-PDF, and page-render workflows, with canonical
  \nolinkurl{docs/PROJECT_MEMORY.md} routing future agents to four focused records.
\end{itemize}

\subsection{Completed lossless-core checkpoints}\label{completed-lossless-core-checkpoints}

\begin{itemize}
\tightlist
\item
  Tasks 1 through 4 pin and build Botan 3.13.0, expose typed domain and secret primitives, bind the fixed Twofish ABI,
  and implement PasswordSafe key derivation, wrapping, CBC, HMAC, and randomness.
\item
  Tasks 5 through 8 implement encrypted snapshots, bounded payload owners, the ordered lossless document model, official
  field schemas and custom properties, quarantined authenticated parsing, validated serialization, and exact candidate
  reopen comparison.
\item
  Tasks 9 and 10 implement revision-safe sessions, explicit secret leases, protected-record rules, atomic local
  publication, external-change detection, and one encrypted recovery revision.
\item
  The latest completed checkpoint is commit \passthrough{\lstinline!32e2d82!}
  (\passthrough{\lstinline!feat: add transactional local vault storage!}).
\end{itemize}

\subsection{Active work}\label{active-work}

Task 11 is next. Its original file map assumes creation, passphrase rotation, independent export, and baseline
advancement primitives that Tasks 7 through 10 do not expose. The user approved a minimal Task 11 amendment covering
\passthrough{\lstinline!reader.py!}, \passthrough{\lstinline!writer.py!}, \nolinkurl{storage.py}, and
\nolinkurl{session.py} before the service facade is assembled. Implement the amendment with failing tests first,
preserve the existing security boundaries, and commit Task 11 independently as planned.

\subsection{Active risks}\label{active-risks}

\begin{itemize}
\tightlist
\item
  The App Store distribution exception, contributor permissions, dependency eligibility, and current Apple terms remain
  unresolved and block external contributions and an iOS distribution build.
\item
  Some Gorilla behaviors remain explicitly Unverified; they do not establish parity until black-box evidence is reviewed
  and the dossier and matrix are updated.
\item
  Python 3.14 support for future binary and mobile dependencies must be requalified in the owning subproject.
\item
  Hosted CI has not run; only its complete local equivalent has passed. Ignored review PDFs must be regenerated from
  committed Markdown and LaTeX.
\item
  The public facade, generative and fuzz evidence, independent interoperability fixtures, mobile cross-build gates, and
  final operational documentation remain incomplete in Tasks 11 through 15.
\end{itemize}

\subsection{Next approved scope}\label{next-approved-scope}

Finish \textbf{Lossless PasswordSafe core} Tasks 11 through 15. Do not start desktop/mobile clients, provider
coordination, or URL-audit behavior until this core passes its complete release gate.
